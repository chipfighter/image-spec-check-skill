# image-spec-check：生图要求清单与出图核对 skill

让 agent 用 AI 生图、改图时，把你的要求写成一份只保留当前版本的清单，出图后按清单检查一遍再交给你。重点盯生图模型最容易画错的地方：左右手、持物、数量、发饰、人物朝向和环境对不上、反手拿东西。同一处反复画不对时，它会停下来跟你商量换做法，不会换着说法一直抽卡。

只要是能调用生图工具、能看图的多模态 agent 都能用（Claude Code、Codex 等）。

## 它会做什么

1. 把你在对话里提的要求写进 `清单.md`。你改口或撤回时，直接改写原条目，避免旧说法又被带进提示词。
2. 写提示词时，把人物朝向、路的走向、用哪只手拿东西，换成画面里的具体方位来写。参考图是三视图时，提醒模型不要照搬三视图里的站姿。
3. 出图后按清单逐项检查，需要看细节的地方先裁出局部再看。
4. 只有你明确提过的要求没做到，才自动重画。它自己推出来的问题只在交付时标出来，由你决定改不改。
5. 同一条连续两次没做到，就停下来，建议换个做法（改机位、简化动作、拆成两张）。
6. 你指出的问题会写进清单，以后每次都查，同样的错不会第二次漏到你面前。

## 测试

[tests/2026-10-24-方位与姿势](tests/2026-10-24-方位与姿势/) 是一次有 skill 和没 skill 的对比测试：同样 3 张图，从第一次生成一直改到用户认可。那次测的是旧版本。旧版本出图后默认另开一个子代理独立核对，结果漏到用户面前的问题并没有更少，Claude 的 token 却多用了约 1.5～2 倍，核对有时还比用户更严。

现在的版本按这次结果减负了：默认由 agent 自己检查，不另开子代理；只有用户提过的要求不通过才自动重画。减负后的版本还没测过。测试目录里有复现步骤、提示词、脚本和全部图片，更新 skill 时可以照着做新一轮。

## 安装

### 最简单：让你的 AI 帮你装

把下面这句话发给你的 Claude Code 或 Codex：

```
帮我安装这个 skill：https://github.com/chipfighter/image-spec-check-skill
```

装好以后重开一个对话，正常让它生图、改图就行。

### 给 AI 的安装说明

如果你是收到上面这句话的 AI：只把本仓库里的 `image-spec-check/` 文件夹复制到用户的 skills 目录（`tests/` 不用装），然后告诉用户重开对话即可。

- Claude Code：`~/.claude/skills/image-spec-check/`
- Codex：`~/.agents/skills/image-spec-check/`
- 其他 agent：把 `SKILL.md` 当作说明书。

裁局部要用 [ffmpeg](https://ffmpeg.org/)。用户电脑上没有的话，先告诉用户，问一下要不要装；不装的话就看整图检查。

### 手动安装

在本页点 **Code → Download ZIP**，解压后把 `image-spec-check/` 文件夹复制到上面对应的目录。

## 文件

- `image-spec-check/SKILL.md`：skill 本体
- `tests/`：对比测试，每一轮一个文件夹
